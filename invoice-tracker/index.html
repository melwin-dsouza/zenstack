// what it does

Replacing spreadsheet-based invoice tracking

A lightweight invoice and receivables tracking system designed to replace manual spreadsheet-based tracking. It handles invoice records, status tracking, reporting and Excel/CSV import and export through a simple browser interface.

  • Create, edit and track invoices with status (paid, pending, overdue)
  • Follow-up history per invoice
  • Reporting dashboard with charts
  • Bulk import and export via Excel/CSV
